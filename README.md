# Getting started

This repository is a sample application for users following the getting started guide at https://docs.docker.com/get-started/.The application is based on the application from the getting started tutorial at https://github.com/docker/getting-started

This project demonstrates how to containerize a simple Node.js Todo Application using Docker. The application is a basic todo list manager that allows users to add, complete, and delete tasks. The main goal of this project is to understand how Docker works in a real-world scenario by building an image, running a container, updating the application, and managing container lifecycle operations.

The project structure includes essential files such as the Dockerfile, package.json, and application source code inside the src directory. The Dockerfile defines the steps required to build the application image, including setting up a Node.js environment, copying the application code, installing dependencies, and running the application on port 3000.
